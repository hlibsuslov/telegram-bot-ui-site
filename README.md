# telegram-bot-ui-site

Landing page for [telegram-bot-ui](https://github.com/hlibsuslov/telegram-bot-ui), an open-source Agent Skill for Telegram bot UI and UX.

Next.js (App Router) + Tailwind CSS + shadcn/ui. Sections are adapted from 21st.dev blocks; the chat mock-ups are hand-drawn SVG in `src/components/chat/`.

```bash
npm install
npm run dev
```

```bash
npm run lint && npm run build
```

`npm test` runs the emoji API contract tests (`tests/contract/`) with Node's own test runner; it needs
Node 22.15 or newer (`module.registerHooks`). The tagger's checks are `py -3 scripts/emoji_taxonomy.py check --gate`
and `py -3 -m unittest scripts/test_emoji_taxonomy.py`.

The API's per-client rate limits key on `x-real-ip` / `x-forwarded-for`. On Vercel the edge sets these; behind any
other host, put the app behind a proxy that overwrites them, or a caller can choose its own bucket.

## Content

- Every claim comes from the skill repository. Facts, install commands and FAQ live in `src/content/site.ts`; update it with each skill release.
- Agent docs: `/agents.md`, `/llms.txt` and `/llms-full.txt` (in `public/`) and the version, Bot API, hosts and commands behind `/agents` (`src/content/agents.generated.json`) are generated by the skill repository in `docs/agents/`. Copy them with `py -3 scripts/sync_agent_docs.py --skill ../telegram-bot-ui` and commit the result; `--check` exits 1 when a copy differs. Never edit them by hand. `npm test` checks that the site shows that version and that the links in them resolve.
- Demo video: web copies in `public/video/` (58 s, 1280x720 H.264 MP4 with faststart and VP9 WebM, ~4.4 MB and ~3.5 MB; v2 with real bot-ui Studio footage), wired up in `DEMO_VIDEO` in `src/content/site.ts`. It loads only when played, autoplays muted while in view and never autoplays with reduced motion.
- Studio: `/studio` embeds the offline build of the Pulloa project in `demo/bot-ui/`. Build the public-demo client with `npm run build:artifact` in its `studio/web` folder, then run `python scripts/build_demo.py --studio /path/to/studio` here. Refresh the lossless screenshots in `public/studio/` from that build when the UI changes: map at 1440×700 and 390×420, simulator after the order.happy scenario at 500×620, receipt screen editor (order.receipt) at 760×620.
- The GitHub star count is fetched at build time and refreshed hourly.
- `NEXT_PUBLIC_SITE_URL` overrides the canonical origin. Production defaults to `https://telegram-bot-ui.hlixli.com`, and Vercel previews use their own origin.
- The catalog, pack pages, and sitemap use the existing server-side `EMOJI_RESOLVER_BOT_TOKEN`. Pack pages and the sitemap resolve data on request. The documentation and other site pages also render locally without the resolver.
- The [Emoji Library API reference](https://telegram-bot-ui.hlixli.com/emoji/api-docs) documents pack search, pack contents, and reverse ID lookup.
